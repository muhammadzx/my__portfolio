# Personal Portfolio

## About

This is a responsive personal portfolio website created using HTML and CSS.
The website presents my personal information, skills, projects, and contact information.

## Features

- Responsive design for desktop, tablet, and mobile devices
- Hero / Landing section
- About Me section
- Projects Gallery
- Contact Form
- Footer
- Hover effects and transitions
- CSS animations
- Box shadows
- Flexbox layout

## Technologies Used

- HTML5
- CSS3

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
